# container-registry-k8s

[![App Status](https://argocd.local/api/badge?name=container-registry&revision=true)](https://argocd.local/applications/container-registry)
![Zot](https://img.shields.io/badge/Zot_Registry-OCI-2496ED?logo=docker&logoColor=white)
![Kubernetes](https://img.shields.io/badge/Kubernetes-1.35-326CE5?logo=kubernetes&logoColor=white)

OCI-compliant container registry for the homelab cluster, powered by **Zot** — a lightweight, single-binary registry that implements the OCI Distribution Specification. Images pushed here are available to all cluster nodes without pulling from Docker Hub.

---

## Architecture

```
  Developer (WSL)                      Kubernetes Nodes
       │                                      │
       │  docker push zot.local/image:tag     │  imagePullPolicy: Always
       ▼                                      ▼
  ┌─────────────────────────────────────────────────────────┐
  │  nginx-ingress-zot (192.168.56.23)                      │
  │  TLS termination — cert from Vault via ExternalSecret   │
  └─────────────────────┬───────────────────────────────────┘
                        │  HTTP (internal)
              ┌─────────▼──────────┐
              │   Zot Registry     │
              │   ClusterIP :5000  │
              │   namespace:       │
              │   container-       │
              │   registry         │
              └─────────┬──────────┘
                        │  stores layers
              ┌─────────▼──────────┐
              │   PVC 50Gi         │
              │   nfs-client       │
              └────────────────────┘
```

## Pushing Images

```bash
# 1. Add hosts entry (if not already done)
# Windows: C:\Windows\System32\drivers\etc\hosts
# WSL:     /etc/hosts
# 192.168.56.23  zot.local

# 2. Trust the CA (if not already done)
# The homelab CA was generated by generate-certs.sh
# WSL:
sudo cp ~/homelab-ca.crt /usr/local/share/ca-certificates/homelab-ca.crt
sudo update-ca-certificates

# 3. Log in (no auth configured by default)
docker login zot.local

# 4. Tag and push
docker tag myimage:latest zot.local/myimage:latest
docker push zot.local/myimage:latest

# 5. Browse the UI
# https://zot.local  — Zot web UI (search extension enabled)
```

## Pulling from Kubernetes

```yaml
spec:
  containers:
  - name: my-app
    image: zot.local/myimage:latest
  imagePullPolicy: Always
```

> Nodes pull via the internal `zot.container-registry.svc.cluster.local:5000` service if you reference by DNS, or via `zot.local` if nodes also resolve it. Since TLS is terminated at nginx, internal service calls use plain HTTP.

For internal cluster pulls without DNS, use the service directly:
```yaml
image: zot.container-registry.svc.cluster.local:5000/myimage:latest
```
(Add `insecureRegistries` to containerd config on each node if using HTTP internally.)

## TLS Setup

TLS is terminated by `nginx-ingress-zot`. The certificate is stored in Vault and synced automatically:

```
Vault (engine: tls, path: zot)
  tls.crt + tls.key
       │  ExternalSecret: zot-tls.yaml
       ▼
K8s Secret: zot-tls (namespace: container-registry)
       │  nginx-ingress-zot reads this secret
       ▼
HTTPS at zot.local
```

To populate the cert (run once, after Vault is initialized):
```bash
kubectl port-forward -n hashicorp-vault svc/hashicorp-vault 8200:8200 &
export VAULT_ADDR=http://127.0.0.1:8200
export VAULT_TOKEN=$(jq -r '.root_token' ~/vault-init.json)
# generate-certs.sh handles zot automatically
/mnt/c/Users/iacob/Documents/repos/ArgoCD/generate-certs.sh
```

## Troubleshooting

**`docker push` fails with `connection refused` or TLS error**
```bash
# Verify ingress is up and IP is assigned
kubectl get ing -n container-registry

# Check nginx-ingress-zot controller
kubectl get pods -n ingress-nginx-zot

# Verify TLS secret exists
kubectl get secret zot-tls -n container-registry
```

**Zot pod not starting (startup probe failing)**
```bash
kubectl describe pod -n container-registry -l app.kubernetes.io/name=zot
kubectl logs -n container-registry -l app.kubernetes.io/name=zot
```

**PVC not bound**
```bash
kubectl get pvc -n container-registry
# Ensure NFS provisioner is running
kubectl get pods -n nfs
```

**Ingress ADDRESS empty**
```bash
# nginx-ingress-zot ArgoCD app must be synced first
kubectl get svc -n ingress-nginx-zot
```
